## 📁 File Naming Convention (Underscore Format)

### Current → New Naming:
```
# Free Plugin
includes/Core.php              → includes/class-core.php ❌ (WordPress uses class- prefix OR namespace PascalCase)

# Decision: Keep PSR-4 PascalCase for PHP classes (it's the modern WP standard)
# Use underscore_case for non-class files, views, assets, and Pro plugin consistency

# Asset files (already correct):
assets/js/form-builder.js      ✅ Already underscore
assets/css/admin.css           ✅ Already underscore

# Pro plugin files to rename:
ProCore.php                    → Pro_Core.php
FileUpload.php                 → File_Upload.php
PageBreak.php                  → Page_Break.php  
StarRating.php                 → Star_Rating.php
ConditionalEngine.php          → Conditional_Engine.php
MultiStep.php                  → Multi_Step.php
StripeHandler.php              → Stripe_Handler.php

# Free plugin files to rename:
EntriesTable.php              → Entries_Table.php
ExportHandler.php             → Export_Handler.php
FormHandler.php               → Form_Handler.php
FeatureGate.php               → Feature_Gate.php
TemplateManager              → Template_Manager (in Templates/)
```

## 🎨 Upsell Visual Strategy

### Current: Simple PRO badge + modal
### Target: Blurred Preview Cards

Each locked feature shows a VISUAL preview:
1. **Blurred Screenshot** of the feature in action
2. **Feature Title + Description**
3. **"Unlock with Pro" CTA**
4. **Animated hover effect** — slight unblur on hover to tease

This is how WPForms, Elementor, and Rank Math do it. It converts 3-5x better than plain badges.

Implementation:
- Generate preview images for each Pro feature
- Display with CSS blur(8px) + overlay gradient
- On hover: reduce blur to blur(4px) for tease effect
- Click opens Freemius checkout or detailed modal
