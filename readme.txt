== Description ==

**GenForm** is a powerful yet simple form builder that makes creating WordPress forms effortless. Whether you need a contact form, quote request, or support ticket form, GenForm provides a premium experience for both users and administrators.

= 🎯 Why Choose GenForm? =

* **Intuitive Builder** - Drag-and-drop interface that makes form creation a breeze.
* **Modern Interface** - Clean admin design with a focus on usability.
* **Blazing Fast AJAX** - Submit forms without page reloads for a smooth user experience.
* **Pixel Perfect** - Responsive forms that look great on any device or theme.
* **Developer Friendly** - Clean, standards-compliant code built with security in mind.

= ✨ Key Features =

**Advanced Form Builder**
* Drag & drop interface with live preview.
* 10 premium field types to choose from.
* Fully customizable labels, placeholders, and CSS classes.
* Smart validation (Required, Email, URL).
* Easy field reordering.

**10 Field Types**
* Single Line Text
* Paragraph Text (Textarea)
* Email Address
* Number

**Customizable Email Notifications**

== Installation ==

= Automatic Installation =

1. Log in to your WordPress admin panel.
2. Go to **Plugins > Add New**.
3. Search for "GenForm".
4. Click "Install Now" and then "Activate".

= Manual Installation =

1. Download the plugin zip file.
2. Go to **Plugins > Add New > Upload Plugin**.
3. Choose the downloaded file and click "Install Now".
4. Activate the plugin.

= Getting Started =

1. Navigate to **GenForm > Add New** in your dashboard.
2. Enter a descriptive name for your form.
3. Drag fields from the sidebar onto the canvas.
4. Click "Edit" on any field to customize its properties.
5. In the **Settings** tab, configure success messages or redirects.
6. In the **Notifications** tab, set up your email alerts.
7. Click **Save Form**.
8. Insert your form using the Gutenberg Block or the provided Shortcode.

== Frequently Asked Questions ==

= Is GenForm free? =

Absolutely! GenForm is 100% free and open source.

= How do I add a form to my page? =

You have two easy ways:
1. **Gutenberg Block**: Add the "GenForm" block and select your form from the dropdown.
2. **Shortcode**: Copy `[genform id="X"]` from the "All Forms" list and paste it anywhere.

= Where do the submissions go? =

They are safely stored in your own database. You can view them anytime under **GenForm > Entries**.

= Can I customize the email alerts? =

Yes! Each form has its own "Notifications" tab where you can change the recipient, subject, and body content using dynamic tags.

= Does it support AJAX? =

Yes, all forms use AJAX by default for a modern, no-refresh submission experience.

= Can I style the forms? =

Yes! Forms inherit your theme's default styles for a consistent look. You can also add custom CSS classes to individual fields for specific styling.

= Is it mobile responsive? =

Yes, every form generated is fully responsive and optimized for mobile devices.
